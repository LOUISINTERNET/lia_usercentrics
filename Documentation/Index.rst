================
LIA Usercentrics
================

This TYPO3 extension integrates a cookie banner for managing consent for 
external services such as analytics, social media, etc. It ensures that 
external sources (like YouTube videos, Vimeo, or other integrated services)
are blocked by default until the user grants consent for their use.
